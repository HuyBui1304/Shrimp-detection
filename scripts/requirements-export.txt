# Bộ phiên bản đã kiểm chứng cho việc xuất models/best.pt sang TFLite.
#
#     python3.11 -m venv .venv-export
#     .venv-export/bin/pip install -r scripts/requirements-export.txt
#     .venv-export/bin/python scripts/export_tflite.py
#
# Chỉ dùng cho việc xuất model. App Flutter không cần gì trong này, và web app
# FastAPI dùng requirements.txt ở thư mục gốc.
#
# Ghi chú về một cảnh báo `pip check` sẽ xuất hiện và có thể bỏ qua:
#
#     litert-torch 0.9.2 has requirement torch<2.13.0, but you have torch 2.13.0
#
# ultralytics khai litert-torch là phụ thuộc bắt buộc, nhưng nó chỉ được nạp khi
# chạy `yolo export format=litert`. scripts/export_tflite.py đi đường
# .pt -> ONNX -> onnx2tf -> TFLite nên không bao giờ chạm tới gói đó.
#
# Nếu bạn thực sự cần đường export gốc của ultralytics, hạ torch xuống dưới
# 2.13 kèm torchvision tương ứng:
#     .venv-export/bin/pip install "torch==2.12.1" "torchvision==0.27.1"
# Lưu ý hai gói này phải hạ cùng nhau — lệch cặp là torchvision hỏng với lỗi
# `RuntimeError: operator torchvision::nms does not exist`.
